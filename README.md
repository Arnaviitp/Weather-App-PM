🌦️ Advanced Weather App

A modern, animated, colorful Weather Application built using HTML, CSS, and JavaScript.
It supports location search, GPS-based weather, 5-day forecast, glassmorphism UI, animated gradients, and emoji-based weather icons.

Built by Arnav Anand.

🚀 Features
🔍 Smart Location Input

Users can enter:

City name (e.g., Delhi)

ZIP code (e.g., 10001)

Landmarks (e.g., Taj Mahal)

Coordinates (e.g., 19.07, 72.87)

Fuzzy matching is provided using the Open-Meteo Geocoding API.

📍 Use My Location

Single-click GPS detection using the device’s location services.

🌤️ Real-Time Weather

Powered by Open-Meteo Weather API:

Current temperature

Weather condition (emoji icons)

Wind speed

Wind direction

📅 5-Day Forecast

Displays daily:

Weather condition

Min/Max temperature

Precipitation

Animated floating weather emoji icons

Glassmorphism cards

Hover animations

Glow effects
