# 🌦️ Advanced Weather App  
**A modern, interactive, animated weather application built using HTML, CSS, and JavaScript.  
Includes geolocation support, fuzzy location search, animated UI, dark mode, gradients, glassmorphism, and more.**

---

## 🚀 Features

### ✅ **1. Search Weather by Location**
- Enter **city name**, **ZIP code**, **landmark**, or **coordinates (lat, lon)**  
- Uses **Open-Meteo Geocoding API** for fuzzy location matching  
- Validates locations & handles errors gracefully

### 📅 **2. 5-Day Weather Forecast**
- Shows animated icons, emojis, precipitation, min/max temperatures  
- Beautiful **glassmorphism forecast cards**  
- Floating emoji animations

### 🎨 **3. Modern UI/UX Enhancements**
- Colorful animated **gradient background**  
- Glassmorphism containers  
- Hover glow effects  
- Smooth transitions  
- Loading skeletons  
- Neumorphic shadows  
- SVG/icon animations

### 🌓 **4. Full Light/Dark Mode Toggle**  
- Background gradients adapt beautifully  
- All components auto-adjust  
- Smooth transitions

### 📍 **5. Use My Location**  
- Uses browser Geolocation API  
- Auto-fetches real-time weather for your device's location

### 📡 **6. Weather API Integration**
API Used: **Open-Meteo.com (Free, No Key Required)**  
- Current weather  
- Weather code → emoji mapping  
- 5-day forecast  
- Timezone auto detection  

### 🗂️ **7. Clean Code + Modular Functions**
- `searchWeather()`  
- `fetchWeather()`  
- `showCurrentWeather()`  
- `showForecast()`  
- `useMyLocation()`  
- `weatherIcon()`  
- Reusable UI helpers
